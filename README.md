## ⚙️ What this tool does

The CS2 Transparent Smoke Utility changes how smoke grenades look in Counter-Strike 2. Standard smoke grenades create thick, opaque clouds. These clouds block your vision entirely. This utility modifies the game assets to make those clouds transparent. You can see through smoke like glass. This gives you a clear line of sight while other players see a wall of smoke.
